# Taccuino dell'Avventuriero

Gestionale per campagne di D&D 5e: scheda personaggio, inventario, incantesimi (in italiano), note, missioni, PNG, dadi e iniziativa.

Funziona nel browser e si installa sul telefono come app (iPhone: Safari → Condividi → "Aggiungi alla schermata Home"; Android: Chrome → menu → "Installa app"). I dati restano salvati sul dispositivo; usa Esporta/Importa per i backup.

Il compendio degli incantesimi deriva dal System Reference Document 5.1 di Wizards of the Coast, rilasciato con licenza Creative Commons Attribution 4.0 (CC-BY-4.0), tradotto in italiano.
