# Taccuino dell'Avventuriero

Gestionale per campagne di giochi di ruolo fantasy, compatibile con la 5ª edizione: scheda personaggio, inventario, incantesimi in italiano, bestiario, note, missioni, PNG, dadi e iniziativa.

Funziona nel browser e si installa sul telefono come app (iPhone: Safari → Condividi → "Aggiungi alla schermata Home"; Android: Chrome → menu → "Installa app"). I dati restano salvati sul dispositivo; usa Esporta/Importa per i backup.

## Contenuti homebrew

Puoi importare razze, sottoclassi, mostri, incantesimi e regole da un file del Taccuino. Importa solo contenuti creati da te o che hai il diritto di usare: le condizioni d'uso (nell'app, menu ☰ → Condizioni d'uso e crediti) vietano il caricamento di materiale protetto da copyright. I contenuti homebrew restano solo sul tuo dispositivo.
